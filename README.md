# AlphaPulse Pro Terminal

A single-file US options dashboard that scans a watchlist for long call / long put setups, scores each contract, and lets you paper-trade the picks with realistic broker fees. A tiny local Node.js bridge supplies market data from Yahoo Finance and, optionally, live option quotes from a running **Moomoo OpenD** gateway.

> **Disclaimer:** This project is for education and paper trading only. It is not financial advice and it does not place real orders. Option prices from Yahoo are delayed (about 15 minutes). It is an independent project and is not affiliated with or endorsed by Moomoo, Futu, or Yahoo.

---

## Features

- **Auto-Picks scanner**: scans your watchlist and ranks contracts in two modes:
  - **Intraday** (0-3 DTE)
  - **Swing** (5-14 DTE)
- **Tiered setups**: `Strict` (score 75+), `Balanced` (60+), `Aggressive` (45+).
- **Per-pick data**: mid, bid/ask, delta, daily theta, IV, open interest / volume, trend and RSI, suggested stop and target, earnings warning.
- **Paper trading**: open positions with editable quantity, entry, stop and target; live P&L; close positions into a realized-P&L record.
- **Fee model**: configurable per-contract fee per side (default **$0.69**, including OCC $0.025 and ORF $0.0122). Round-trip fees are deducted from every P&L figure.
- **Moomoo live quotes (optional)**: when OpenD is connected, open paper positions are priced from Moomoo instead of the delayed Yahoo feed (shown as `[Moomoo]` next to the price).
- **Chart links**: one click opens the exact contract on moomoo.com.
- **Auto-sync**: open positions refresh every 15 seconds; bridge status is checked every 10 seconds.
- **Zero build step**: one `index.html`. Settings and trades are stored in your browser's `localStorage`.

## How the scoring works

For each symbol the app computes a trend bias from EMA20/EMA50, RSI and the day's change. Symbols with a weak bias (|bias| < 30) are skipped. Bullish bias selects calls, bearish selects puts.

Contracts are filtered (ask > 0, mid ≥ $0.10, open interest ≥ 100, valid IV) and scored out of 100 on:

| Factor | Weight |
| --- | --- |
| Trend strength | 25 |
| Delta close to target (0.45 intraday, 0.40 swing) | 15 |
| Bid/ask spread tightness | 15 |
| Volume | 10 |
| IV relative to 21-day historical vol | 10 |
| Theta decay relative to price | 10 |
| Fundamentals (analyst rating, forward vs trailing P/E) for single stocks | 10 |

An earnings date inside the holding window subtracts 8 points. Suggested exits are a stop at 65% (intraday) or 60% (swing) of mid, and a target at 150% or 180% of mid.

## Requirements

- A modern browser (Chrome, Edge or Firefox)
- **Node.js 22 or newer** (the bridge uses the built-in `fetch`, and the Moomoo SDK needs the built-in `WebSocket`)
- *Optional:* [Moomoo OpenD](https://openapi.moomoo.com/moomoo-api-doc/en/quick/opend-base.html) (visual version), logged in to your Moomoo account, with US option quote permission

## Quick start

1. **Get the files.** Clone the repo or download `index.html`.
2. **Get the bridge.** Open `index.html` in your browser, go to **Settings**, and click **Download Bridge (server.js)**. The bridge code is embedded in the page, so the downloaded file always matches the page. Save it in an empty folder.
3. **Install and run the bridge:**
   ```bash
   npm i moomoo-api      # only needed for the Moomoo integration
   node server.js
   ```
   It listens on `http://127.0.0.1:8787` (change with the `PORT` environment variable).
4. In the page, the header should show **BRIDGE ONLINE**. Go to **Auto-Picks** and click **Scan Scanner**.

> If you ever update `index.html`, download `server.js` again and restart the bridge so both stay in sync.

## Connecting Moomoo OpenD (optional)

The bridge talks to OpenD over its **WebSocket** port, which is different from the normal API port.

1. Start **OpenD** and log in. In its main window you will see:
   - **API Port** `11111`
   - **WebSocket Port** `33333`
   - **WebSocket Auth**: a key generated by OpenD (for example `jVyM18lup3jWFj4S`)
2. In the dashboard open **Settings → Moomoo OpenAPI Direct Gateway**:
   - OpenD Host: `127.0.0.1`
   - OpenD WebSocket Port: `33333`
   - **WebSocket Key: the *WebSocket Auth* value shown in the OpenD window**
   - API Secret: leave empty (not used by the WebSocket login)
3. Click **Connect Gateway**. You should see `✔ Connected to OpenD at 127.0.0.1:33333` and the header changes to `BRIDGE ONLINE · MOOMOO LINKED`.

To avoid retyping the key, start the bridge with it:

```bash
# macOS / Linux
MOOMOO_KEY=yourWebSocketAuth node server.js

# Windows PowerShell
$env:MOOMOO_KEY="yourWebSocketAuth"; node server.js
```

The key is held in the bridge's memory only. It is not saved to disk by the dashboard.

### Troubleshooting

| Message | Meaning and fix |
| --- | --- |
| `No login response from OpenD … after 8s` | Nothing is answering as a WebSocket on that port. Use the **WebSocket Port** from the OpenD window (not the API port 11111) and make sure OpenD is running. |
| `OpenD refused the connection: no message (code -1)` | The key is wrong. Copy the **WebSocket Auth** value from the OpenD window exactly (it is case-sensitive). The key may change when OpenD restarts. |
| `moomoo-api not installed` | Run `npm i moomoo-api` in the same folder as `server.js`. |
| `Bridge connection failed` | The bridge is not running, or **Local Bridge URL** in Settings does not match its address. |
| Many `ErrorEvent` / `CloseEvent` lines in the bridge terminal | You pointed the bridge at OpenD's API port (11111) instead of the WebSocket port. |
| Live prices still show `[Yahoo]` | Moomoo returns no quote for that contract. Check that your account has US option quote permission and that OpenD is connected. |

## Bridge API

The bridge is a plain Node HTTP server bound to `127.0.0.1` only.

| Endpoint | Purpose |
| --- | --- |
| `GET /api/chain?symbol=SPY&date=<unix>` | Option chain (Yahoo) |
| `GET /api/quote?symbols=SPY,QQQ` | Quotes (Yahoo) |
| `GET /api/chart?symbol=SPY&range=6mo&interval=1d` | Price history (Yahoo) |
| `GET /api/moomoo/quote?code=<OCC symbol>` | Live option quote via OpenD |
| `GET /api/moomoo/status` | OpenD connection status |
| `POST /api/moomoo/config` | Set OpenD host, port and key |

## Configuration

All settings are in the **Settings** tab and saved to `localStorage`:

- **Local Bridge URL** (default `http://127.0.0.1:8787`)
- **Watchlist symbols** (default `SPY,QQQ,IWM,AAPL,MSFT,NVDA,TSLA,AMZN,META`)
- **Fee per contract per side** (default `0.69`)

## Security notes

- Never commit your OpenD key or Moomoo credentials to the repository.
- The bridge only listens on `127.0.0.1`, so other machines cannot reach it. Keep it that way.
- The dashboard does not place orders. Paper trades live only in your browser.

## Limitations

- Yahoo option data is delayed about 15 minutes and Yahoo's unofficial endpoints can change or rate-limit without notice.
- Greeks use a simple Black-Scholes model with a fixed 4.5% risk-free rate.
- Paper P&L uses mid or last prices and does not model slippage or partial fills.
- Clearing browser storage deletes your paper trades. Export or note anything you want to keep.
